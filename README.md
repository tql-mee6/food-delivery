# FoodExpress — доставка еды из ресторанов

Учебный проект: веб-сайт сервиса доставки еды с возможностью выбора ресторана,
оформления заказа и отслеживания его статуса.

## 🎯 Функционал

- **Каталог ресторанов** — поиск, фильтр по кухне, сортировка
- **Меню ресторана** — категории блюд, карточки с ценами и весом
- **Корзина** — добавление, изменение количества, удаление, сохранение между сессиями
- **Оформление заказа** — форма с валидацией (имя, телефон, адрес, комментарий)
- **Отслеживание статуса** — 4 этапа: принят → готовится → в пути → доставлен
- **История заказов** — все заказы пользователя с прогрессом

## 🛠 Технологии

- **Next.js 16** (App Router, TypeScript)
- **Tailwind CSS** — стилизация
- **Zustand** + **localStorage** — состояние корзины и заказов
- **Lucide React** — иконки
- **Framer Motion** — анимации

## 🗂 Структура

\`\`\`
app/
├── restaurants/       ← каталог и меню ресторанов
├── cart/              ← корзина
├── checkout/          ← оформление заказа
├── order/[id]/        ← статус конкретного заказа
├── orders/            ← история заказов
├── components/        ← переиспользуемые компоненты
└── not-found.tsx      ← страница 404

lib/
├── restaurants.ts     ← данные ресторанов
├── menu.ts            ← данные меню
├── cartStore.ts       ← Zustand-стор корзины
└── ordersStore.ts     ← Zustand-стор заказов

types/
└── index.ts           ← TypeScript-типы
\`\`\`

## 💾 Данные

На текущий момент данные хранятся в:
- **Рестораны и меню** — статические файлы в `lib/`
- **Корзина и заказы** — `localStorage` браузера

В будущем планируется переход на базу данных (PostgreSQL + Prisma)
для хранения ресторанов, заказов и пользователей.

**Проверка адаптива:**
1. Откройте сайт в браузере
2. `F12` → `Ctrl + Shift + M` (режим мобильного)
3. Выберите iPhone
4. Пройдите по всем страницам — убедитесь, что всё читается и работает

**Деплой на Vercel:**
1. Откройте **GitHub Desktop**
2. Если проект `food-delivery` ещё не в GitHub:
   - **File** → **Add Local Repository** → выберите папку `food-delivery`
   - **Create repository here instead** (если предложит)
   - **Publish repository** → назовите `food-delivery`
3. Если уже в GitHub — просто **Commit to main** → **Push origin**
4. Откройте [vercel.com/dashboard](https://vercel.com/dashboard) → **Add New** → **Project** → **Import** `food-delivery`
5. **Deploy** (переменных окружения не нужно — у нас нет БД)

Через 2–3 минуты получите ссылку — покажете преподавателю и добавите в портфолио.
